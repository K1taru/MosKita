Project Title
MosKita: A YOLO-Based Dengue Mosquito Breeding Site Detection System for Edge-Ready Community Surveillance

## Abstract
MosKita is an object detection project that identifies potential dengue mosquito breeding containers from field images and camera streams. The final model in this report is the 70-epoch run from the project notebook output, saved under run name moskita_v1210 and exported to ONNX for deployment workflows. The study uses an 8-class taxonomy and evaluates performance using precision, recall, mAP@50, and mAP@50-95 on validation and held-out test data. The final checkpoint achieved mAP@50 of 0.9102 on validation and 0.9340 on test, with corresponding mAP@50-95 of 0.7861 and 0.7985. Results show strong detection performance for deployment-oriented surveillance, with identified risks in class imbalance and low-support classes. This report follows IEEE-style technical structure and uses APA-style references (2021 onward) from legitimate, visitable sources.

Keywords: dengue surveillance, mosquito breeding site detection, YOLO object detection, edge AI, ONNX, Raspberry Pi 5
