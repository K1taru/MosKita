2. Background:

### 2.1 Problem Context
Dengue remains a major vector-borne disease burden in tropical and subtropical regions. WHO reports that dengue risk now affects roughly half of the global population and that prevention still relies heavily on vector control and habitat management (World Health Organization, 2025). In this context, rapid detection of potential breeding containers in community environments is an operationally relevant problem for local surveillance teams.

MosKita addresses this need by detecting visible container types commonly associated with mosquito breeding risk. Rather than classifying a whole image as positive or negative, the project uses object detection so that each potential site is localized with a bounding box and confidence score. This improves actionability for field response and reporting.

### 2.2 Technical Foundation
Modern one-stage detectors in the YOLO family are designed for speed-accuracy tradeoffs in real-time applications. Successive generations have shown strong practical performance by combining efficient backbones, detection heads, and training strategies (Ge et al., 2021; Wang et al., 2022). The current project uses the Ultralytics training stack and a lightweight YOLO-family checkpoint for custom fine-tuning and export workflows (Ultralytics, 2026a, 2026b).

The deployed workflow also requires cross-platform inference compatibility. ONNX-based export supports this requirement by allowing model execution with ONNX Runtime across different hardware/software environments (Microsoft, 2026).

In parallel with YOLO-family progress, recent real-time detection literature has also explored transformer-based alternatives such as RT-DETR, which report competitive accuracy-speed tradeoffs under end-to-end detection design (Lv et al., 2024). This broader context supports the methodological decision to prioritize a compact real-time detector family for current deployment constraints while leaving room for future architecture comparisons.

### 2.3 Related Work and Relevance
Recent detector literature highlights improvements in both inference efficiency and detector optimization that make near-real-time environmental monitoring feasible on moderate hardware (Ge et al., 2021; Wang et al., 2022). From a domain perspective, global and regional dengue expansion reinforces the need for scalable digital tools that support preventive action (World Health Organization, 2025; Lim et al., 2025).

In practical tooling, current dataset management platforms emphasize versioned export, class-name sanitation, and reproducible training data preparation, all of which are important for robust model development (Roboflow, 2026). Framework-level updates in PyTorch continue to improve ecosystem stability and deployment readiness for ML workloads (PyTorch Foundation, 2025).

Recent vector-surveillance ML studies further support the project direction. MosquitoFusion presented multiclass detection including breeding sites using YOLOv8 (Sayeedi et al., 2024). Vicente et al. (2024) showed object-detection approaches for Aedes egg counting. Kittichai et al. (2021) demonstrated deep-learning based mosquito vector identification in field-like settings. Together, these studies reinforce that detection-focused pipelines are appropriate for operational entomological surveillance tasks.

### 2.4 Research Gap and Project Contribution
Many existing public demonstrations of object detection focus on generic benchmarks and less on localized dengue surveillance scenarios. MosKita contributes by:
1. Defining an operationally grounded 8-class breeding-container schema for project deployment.
2. Documenting a reproducible 70-epoch training run with complete artifacts.
3. Reporting both validation and held-out test metrics, plus class-wise analysis.
4. Providing ONNX export artifacts for edge-oriented inference workflows.

### 2.5 Scope and Constraints
This study focuses on container detection and does not directly infer larval presence, water quality, or epidemiological transmission probability. A detected object is interpreted as a potential breeding site, consistent with the project detection philosophy. Reported performance is bounded by current dataset composition, especially minority classes with low support.
