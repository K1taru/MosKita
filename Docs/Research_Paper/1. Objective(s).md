1. Objective(s):

### Primary Objective
Develop and document an end-to-end object detection pipeline that can identify dengue mosquito breeding containers from images, then prepare the model for practical edge-inference workflows.

### Specific Objectives
1. Build a reproducible 8-class detection dataset under the current project schema:
   discarded_tire, flower_pot, coconut_shell, basin, drain_inlet, drum, bucket, styrofoam_container.
2. Train an Ultralytics YOLO-family detector using a fixed 70-epoch configuration and preserve all training artifacts for traceability.
3. Evaluate the final checkpoint on both validation and held-out test splits using precision, recall, mAP@50, and mAP@50-95.
4. Analyze per-class behavior to identify strong classes, weak classes, and risks caused by class imbalance.
5. Export the final model to ONNX and verify artifact integrity for downstream deployment on resource-constrained hardware.
6. Produce an IEEE-style technical report and instructor-aligned submission checklist that includes methodology, preprocessing, training setup, evaluation, insights, and limitations.

### Learning Outcomes
1. Demonstrate practical understanding of object detection workflow design for public-health surveillance.
2. Apply reproducibility practices in deep learning experiments (seed control, deterministic settings, saved run artifacts).
3. Interpret detection metrics beyond a single score, including class-wise performance and dataset bias effects.
4. Translate a notebook-based experiment into a formal technical report suitable for academic submission.
